# 習慣化バトルパス Issue 化しやすい実装分解

## 1. 使い方

この文書は、GitHub Issue にそのまま落とし込みやすい粒度を意識して分解したものです。

- 1 行目を Issue タイトルに使えるようにする。
- 2 行目以降を Issue 本文の要点として使えるようにする。
- 「完了条件」は、Issue の Done 定義としてそのまま使えるようにする。
- 「依存 Issue」は、起票順の目安として使う。

## 2. Issue 一覧

  - 開発用のビルド・起動方法を整える。

  - ローカルで起動できる。
  - 画面遷移の土台ができている。
